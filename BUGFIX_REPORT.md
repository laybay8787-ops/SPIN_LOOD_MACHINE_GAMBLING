## 🔴 Критические баги

### 1. Абсолютные пути в production сборке
**Проблема:** После деплоя на GitHub Pages сайт ломался - все стили и скрипты не загружались.  
**Причина:** Vite генерировал абсолютные пути (`/assets/...`) вместо относительных (`./assets/...`).  
**Решение:** Добавлено `base: './'` в `vite.config.ts`.  
**Файлы:** `vite.config.ts`  
**Статус:** ✅ FIXED

---

### 2. Плашка долга перекрывала toast уведомления
**Проблема:** Индикатор долга в правом нижнем углу перекрывался toast уведомлениями об автокредите.  
**Причина:** Неправильное позиционирование и z-index.  
**Решение:** 
- Перемещена плашка в самый конец компонента
- Установлен `z-index: 99999`
- Использованы inline styles для гарантии позиционирования  
**Файлы:** `src/App.tsx` (строка ~1524)  
**Статус:** ✅ FIXED

---

### 3. Макаки залетали на территорию барабанов
**Проблема:** Кибер-макаки пролетали через барабаны, перекрывая символы.  
**Причина:** Макаки были внутри контейнера с барабанами.  
**Решение:** 
- Создана внешняя зона полёта с `padding: 100px` и `margin: -100px`
- Макаки перемещены во внешний контейнер
- Обновлены CSS анимации для полёта по периметру  
**Файлы:** `src/App.tsx`, `src/index.css`  
**Статус:** ✅ FIXED

---

### 4. Баланс не обновлялся при автокредите
**Проблема:** При установке ставки 10 000 000 с балансом 20 кредитов, 20 кредитов не списывались.  
**Причина:** Race condition между `balanceRef.current` и `setBalance`.  
**Решение:** Добавлено синхронное обновление `balanceRef.current` в функции `autoLoan`.  
**Файлы:** `src/App.tsx` (строка ~595)  
**Статус:** ✅ FIXED

---

### 5. Race condition в doSpin
**Проблема:** При быстром нажатии SPIN баланс мог обновляться некорректно.  
**Причина:** Использовалось функциональное обновление `setBalance((b) => b - currentBet)` без синхронизации с `balanceRef`.  
**Решение:** 
```typescript
const newBalance = balanceRef.current - currentBet;
setBalance(newBalance);
balanceRef.current = newBalance; // Синхронизируем ref
```  
**Файлы:** `src/App.tsx` (строка ~637)  
**Статус:** ✅ FIXED

---

### 6. Отсутствие обработки ошибок localStorage
**Проблема:** В режиме инкогнито или при переполнении localStorage приложение могло падать.  
**Причина:** Все операции с localStorage выполнялись без try-catch.  
**Решение:** Добавлены try-catch блоки во все операции с localStorage:
- Сохранение баланса
- Сохранение betIndex
- Очистка данных в resetGame  
**Файлы:** `src/App.tsx` (строки ~526, ~531, ~1005)  
**Статус:** ✅ FIXED

---

### 7. Отсутствие инициализации из localStorage
**Проблема:** При обновлении страницы баланс и ставка сбрасывались к значениям по умолчанию.  
**Причина:** Состояние инициализировалось значениями из CONFIG, а не из localStorage.  
**Решение:** Добавлена инициализация из localStorage с обработкой ошибок:
```typescript
const [balance, setBalance] = useState<number>(() => {
  try {
    const saved = localStorage.getItem(CONFIG.STORAGE_PREFIX + 'balance');
    return saved ? parseFloat(saved) : CONFIG.DEFAULT_START_BALANCE;
  } catch (e) {
    return CONFIG.DEFAULT_START_BALANCE;
  }
});
```  
**Файлы:** `src/App.tsx` (строки ~452, ~468)  
**Статус:** ✅ FIXED

## 🟡 Незначительные баги

### 8. Демо-версия перекрывала контент
**Проблема:** Плашка "Демо-версия" на стартовом экране была слишком большой и перекрывала элементы.  
**Причина:** Использовался glass-panel с большими отступами.  
**Решение:** Уменьшена до компактной строки с `opacity: 60%`.  
**Файлы:** `src/App.tsx`  
**Статус:** ✅ FIXED

---

### 9. Кнопки слишком маленькие на десктопе
**Проблема:** На больших экранах (1920px+) кнопки управления были слишком маленькими.  
**Причина:** Не было отдельных стилей для desktop.  
**Решение:** Добавлены media queries для desktop (1024px+):
- Увеличены размеры кнопок
- Увеличены отступы
- Увеличены размеры текста  
**Файлы:** `src/index.css`  
**Статус:** ✅ FIXED

---

### 10. Performance issues с макаками
**Проблема:** 15 анимированных макак вызывали падение FPS на слабых устройствах.  
**Причина:** CSS анимации без GPU acceleration.  
**Решение:** Добавлены оптимизации:
```css
.cyber-monkey {
  will-change: transform;
  transform: translateZ(0); /* GPU acceleration */
}
```  
**Файлы:** `src/index.css`  
**Статус:** ✅ FIXED
