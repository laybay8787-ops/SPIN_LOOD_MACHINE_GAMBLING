## 📋 Описание проекта

Neon Cyber Spin — это полноценная веб-слот машина, созданная на React + TypeScript с использованием Vite. Игра отличается уникальным киберпанк дизайном, плавными анимациями и реалистичной механикой казино.

### ⚠️ Важное предупреждение

**Это демо-версия для развлекательных целей.** Математика игры настроена так, что **казино всегда в выигрыше**:
- RTP (Return to Player): ~10%
- Пользователь выигрывает только в 1 из 10 случаев
- Долг безлимитный — можно уходить в бесконечный минус
- Чем выше долг, тем быстрее крутятся барабаны

## ✨ Основные возможности

### 🎮 Геймплей
- **5 барабанов × 3 ряда** с strip-based анимацией
- **10 линий выплат** (горизонтальные, диагональные, зигзаги)
- **7 типов символов**: 🍒 Вишня, 🍋 Лимон, 🔔 Колокол, 💎 Алмаз, 7️⃣ Семёрка, ⚡ Wild, 🌀 Scatter
- **Максимальная ставка**: 10 000 000 кредитов
- **Автоигра**: 10, 25, 50 или 100 спинов

### 💰 Финансовая система
- **Выбор стартовой суммы**: 500, 1 000, 2 000, 5 000 или 10 000 кредитов
- **Безлимитный автокредит**: при нехватке средств автоматически берётся кредит (500 за раз, 10% комиссия)
- **Внешний долг США**: шуточная функция +1 000 000 кредитов с 25% годовых
- **Динамическая скорость вращения**: чем выше долг, тем быстрее крутятся барабаны (до x4)
- **Индикатор долга**: отображается в правом нижнем углу в реальном времени

### 🎁 Бонусы и фичи
- **Фриспины**: 3+ Scatter = 10 бесплатных спинов с множителем x2
- **Прогрессивный джекпот**: растёт на 1% от каждой ставки
- **Big Win анимация**: конфетти и искры при выигрыше > x20 ставки
- **Near Miss эффект**: в 18% проигрышных спинов показывается "почти выигрыш"

### 🏆 Достижения
9 уникальных ачивок:
- 🗡️ Первая кровь — первый выигрыш
- 💰 Крупная рыба — выигрыш > x50 ставки
- 🎰 Хайроллер — 100 спинов
- 📈 В плюсе — баланс выше стартового после 50 спинов
- 🔥 Серия — 3 выигрыша подряд
- 💎 Алмазный магнат — 5 алмазов на линии
- 🌀 Бонусный охотник — активировать фриспины 3 раза
- 🏦 Должник — взять 5+ займов
- 🎊 Джекпот! — выиграть джекпот

### 🐵 Кибер-макаки
**15 анимированных кибер-обезьян** бегают вокруг барабанов:
- Разные эмодзи: 🐵 🐒 🙊 🙉 🙈 🦧 🦍
- 3 типа анимаций: обычная, reverse (против часовой стрелки), orbit (эллиптическая)
- Разные скорости и размеры
- Неоновое свечение и эффекты

### 📊 Статистика
- Полный трекинг всех спинов
- График баланса в реальном времени
- История последних 10 выигрышей
- Расчёт текущего RTP
- Серии выигрышей/проигрышей

### 🔊 Звуковые эффекты
Все звуки генерируются через **Web Audio API** (без внешних файлов):
- Звук вращения барабанов
- Металлический щелчок при остановке
- Мажорный аккорд при выигрыше
- Фанфары при Big Win
- Магический звук при Scatter
- Эпичная мелодия при джекпоте

## 🛠️ Технологии

### Стек
- **React 18** — UI фреймворк
- **TypeScript 5** — типизация
- **Vite 6** — сборщик
- **Tailwind CSS 3** — стилизация

- `PaylineEvaluator` — проверка линий
- `RNG` — криптографический генератор
- `AudioManager` — звуки
- `LoanSystem` — система займов
- `StatsTracker` — статистика
- `BonusGame` — фриспины
- `Jackpot` — прогрессивный джекпот
- `AchievementSystem` — достижения

## 🌐 Деплой на GitHub Pages

### Автоматический деплой через GitHub Actions

1. **Создайте репозиторий на GitHub**

2. **Загрузите все файлы проекта** (включая `.github/workflows/deploy.yml`)

3. **Включите GitHub Pages**:
   - Перейдите в **Settings** → **Pages**
   - В разделе **Build and deployment** → **Source** выберите **GitHub Actions**

4. **Сделайте push в main/master**:
   ```bash
   git add .
   git commit -m "Initial commit"
   git push origin main
   ```

5. **Дождитесь завершения деплоя** (1-2 минуты)

6. **Откройте сайт**:
   ```
   https://your-username.github.io/repository-name/
   ```

### Ручной деплой

```bash
# 1. Соберите проект
npm run build

# 2. Создайте репозиторий на GitHub

# 3. Загрузите содержимое папки dist/ в репозиторий

git add .

git branch -M main
git remote add origin https://github.com/username/repository-name.git
git push -u origin main

# 4. В настройках репозитория (Settings → Pages):
#    - Source: Deploy from a branch
```

## 🔧 Частые проблемы и решения

### Проблема: Сайт не открывается на GitHub Pages
**Решение:** Убедитесь что в `vite.config.ts` указано `base: './'` и пересоберите проект.

### Проблема: `npm: command not found`
**Решение:** Node.js не установлен. Скачайте с [nodejs.org](https://nodejs.org).

### Проблема: `Port 5173 is already in use`
**Решение:** 
```bash
npm run dev -- --port 3000
```

### Проблема: Белый экран в браузере
**Решение:** 
1. Откройте консоль браузера (F12)
2. Проверьте наличие ошибок
3. Убедитесь, что `npm install` завершился успешно
4. Попробуйте очистить кэш браузера (Ctrl + Shift + R)

### Проблема: Зависимости не устанавливаются
**Решение:** 
```bash
# Удалите node_modules и package-lock.json
rm -rf node_modules package-lock.json  # macOS/Linux
rmdir /s /q node_modules && del package-lock.json  # Windows

# Очистите кэш npm
npm cache clean --force

# Установите заново
npm install
```
