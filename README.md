## 📖 Описание

Neon Cyber Spin — это полноценная веб-слот машина с темой киберпанк, созданная на React + TypeScript. Игра отличается уникальным дизайном с неоновыми эффектами, плавными анимациями и реалистичной механикой казино.

### ⚠️ Важное предупреждение

**Это демо-версия для развлекательных целей.** Математика игры настроена так, что **казино всегда в выигрыше**:
- RTP (Return to Player): ~10%
- Пользователь выигрывает только в 1 из 10 случаев
- Долг безлимитный — можно уходить в бесконечный минус
- Чем выше долг, тем быстрее крутятся барабаны

## ✨ Основные возможности

### 🎮 Геймплей
- **5 барабанов × 3 ряда** с strip-based анимацией
- **10 линий выплат** (горизонтальные, диагональные, зигзаги)
- **7 типов символов**: 🍒 Вишня, 🍋 Лимон, 🔔 Колокол, 💎 Алмаз, 7️⃣ Семёрка, ⚡ Wild, 🌀 Scatter
- **Максимальная ставка**: 10 000 000 кредитов
- **Автоигра**: 10, 25, 50 или 100 спинов

### 💰 Финансовая система
- **Выбор стартовой суммы**: 500, 1 000, 2 000, 5 000 или 10 000 кредитов
- **Безлимитный автокредит**: при нехватке средств автоматически берётся кредит (500 за раз, 10% комиссия)
- **Динамическая скорость вращения**: чем выше долг, тем быстрее крутятся барабаны (до x4)
- **Индикатор долга**: отображается в правом нижнем углу в реальном времени

### 🎁 Бонусы и фичи
- **Фриспины**: 3+ Scatter = 10 бесплатных спинов с множителем x2
- **Прогрессивный джекпот**: растёт на 1% от каждой ставки
- **Big Win анимация**: конфетти и искры при выигрыше > x20 ставки
- **Near Miss эффект**: в 18% проигрышных спинов показывается "почти выигрыш"

### 🏆 Достижения
9 уникальных ачивок:
- 🗡️ Первая кровь — первый выигрыш
- 💰 Крупная рыба — выигрыш > x50 ставки
- 🎰 Хайроллер — 100 спинов
- 📈 В плюсе — баланс выше стартового после 50 спинов
- 🔥 Серия — 3 выигрыша подряд
- 💎 Алмазный магнат — 5 алмазов на линии
- 🌀 Бонусный охотник — активировать фриспины 3 раза
- 🏦 Должник — взять 5+ займов
- 🎊 Джекпот! — выиграть джекпот

### 📊 Статистика
- Полный трекинг всех спинов
- График баланса в реальном времени
- История последних 10 выигрышей
- Расчёт текущего RTP
- Серии выигрышей/проигрышей

### 🔊 Звуковые эффекты
Все звуки генерируются через **Web Audio API** (без внешних файлов):
- Звук вращения барабанов
- Металлический щелчок при остановке
- Мажорный аккорд при выигрыше
- Фанфары при Big Win
- Магический звук при Scatter
- Эпичная мелодия при джекпоте

## 🛠️ Технологии

### Стек
- **React 18** — UI фреймворк
- **TypeScript 5** — типизация
- **Vite 6** — сборщик
- **Tailwind CSS 3** — стилизация

Строгий ООП подход:
- `Game` — главный контроллер
- `Config` — все настройки и константы
- `SlotMachine` — логика барабанов
- `Reel` — отдельный барабан
- `Symbol` — символ с весом
- `PaylineEvaluator` — проверка линий
- `RNG` — криптографический генератор
- `AudioManager` — звуки
- `LoanSystem` — система займов
- `StatsTracker` — статистика
- `BonusGame` — фриспины
- `Jackpot` — прогрессивный джекпот
- `AchievementSystem` — достижения

## 🚀 Установка и запуск

### Требования
- Node.js 18+ 
- npm или yarn

### Установка
```bash
# Клонировать репозиторий
git clone <repository-url>
cd neon-cyber-spin

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Собрать production-версию
npm run build

# Предпросмотр production-сборки
npm run preview
```

### Деплой
Готовый `dist/` folder можно деплоить на любой статический хостинг:
- **Vercel**: `vercel deploy`
- **Netlify**: перетащить `dist/` в Netlify Drop
- **GitHub Pages**: загрузить в репозиторий
- **Любой хостинг**: загрузить файлы через FTP

## 🎯 Как играть

### Начало игры
1. Откройте приложение
2. Введите номер паспорта (шуточная авторизация — можно ввести что угодно)
3. Выберите стартовую сумму
4. Нажмите "ВОЙТИ В КАЗИНО"

### Управление
- **SPIN** (или пробел) — крутить барабаны
- **+/-** — изменить ставку
- **MAX** — максимальная ставка
- **AUTO** — автоигра
- **🔊** — вкл/выкл звук
- **📋** — таблица выплат
- **📊** — статистика
- **🏆** — достижения
- **💰 фиксируем прибыль** — выйти на главный экран

### Советы (которые не помогут)
- 💡 Казино всегда в выигрыше
- 💡 Долг растёт бесконечно
- 💡 Чем больше долг, тем быстрее вы проигрываете
- 💡 Математика против вас

## ⚙️ Конфигурация

Все настройки находятся в `src/game/config.ts`:

### Изменение RTP
```typescript
WIN_CHANCE: 0.10,  // Шанс выигрыша (10%)
PAYTABLE: {
  cherry: { 3: 1, 4: 2, 5: 5 },  // Выплаты
  // ...
}
```

### Изменение ставок
```typescript
BET_LEVELS: [10, 50, 100, 500, 1000, 5000, 10000, 50000, 100000, 500000, 1000000, 5000000, 10000000]
```

### Изменение скорости вращения от долга
```typescript
DEBT_SPEED_THRESHOLDS: [
  { debt: 0, multiplier: 1.0 },
  { debt: 100, multiplier: 0.85 },
  // ...
]
```

## 🐛 Известные ограничения

1. **Клиентский RNG** — все расчёты на клиенте (в продакшене нужен сервер)
2. **Нет серверной валидации** — баланс можно изменить через консоль
3. **LocalStorage** — данные хранятся локально (можно очистить)
4. **Демо-версия** — не предназначена для реальных денег
