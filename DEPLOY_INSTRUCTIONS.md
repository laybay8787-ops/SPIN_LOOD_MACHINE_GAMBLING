## 📋 Пошаговая инструкция

```bash

git add .

# Создайте коммит
git commit -m "Fix: GitHub Pages paths and layout issues"

# Запушьте в репозиторий
git push origin main
```

### Шаг 2: Проверьте GitHub Actions

1. Перейдите в ваш репозиторий на GitHub
2. Откройте вкладку **Actions**
3. Дождитесь завершения workflow "Deploy to GitHub Pages"
4. Убедитесь что все шаги прошли успешно (зелёные галочки)

### Шаг 3: Проверьте настройки GitHub Pages

1. Перейдите в **Settings** → **Pages**
2. В разделе **Build and deployment**:
   - **Source**: выберите **GitHub Actions**
3. Сохраните настройки

### Шаг 4: Дождитесь деплоя

- Деплой занимает 1-3 минуты
- Обновите страницу настроек Pages
- Когда появится зелёная плашка "Your site is live", сайт готов!

## 🔧 Если сайт не открывается

### Проблема 1: 404 ошибка
**Решение:**
1. Проверьте что в `vite.config.ts` указано:
   ```typescript
   base: '/SPIN_LOOD_MACHINE_GAMBLING/'
   ```
2. Пересоберите проект: `npm run build`
3. Запушьте изменения

### Проблема 2: Белый экран
**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте ошибки
3. Убедитесь что пути к файлам правильные:
   - `/SPIN_LOOD_MACHINE_GAMBLING/assets/index-xxx.js`
   - `/SPIN_LOOD_MACHINE_GAMBLING/assets/index-xxx.css`

### Проблема 3: Сдвиг вправо
**Решение:**
1. Очистите кэш браузера (Ctrl+Shift+R)
2. Проверьте что зона полёта макак настроена правильно
3. Проверьте CSS на наличие `overflow: hidden`
